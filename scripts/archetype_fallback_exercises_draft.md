# Черновик упражнений: закрытие content-причин archetype fallback (аудит 2026-09-21)

Источник: расследование ~200 предупреждений "Day-archetype fallback" в 52-недельной
симуляции на копии прод-БД (полный разбор — Artifact
https://claude.ai/artifact/1g344KogHNZoMzXgKECQc1). Из 4 причин две — код-баги (B1, B3),
уже исправлены на ветке `wip/archetype-filter-order` и задеплоены на прод 2026-09-22.
Две другие — нехватка контента в каталоге, закрываются этим черновиком:

- **A** (~69 fallback'ов): difficulty-гейт для новичков/первых недель отсекает весь
  каталог, потому что POWER-контента на difficulty 1 для squat/hip_hinge/pull нет вообще.
- **B2** (~27 fallback'ов): исключение по ротации (variant rotation) оставляет 0
  доступных кандидатов для pull/SKILL и hip_hinge/SKILL — в каталоге слишком мало
  вариантов на эти комбинации, чтобы ротация не съедала единственный подходящий.

Статус: **черновик для проверки пользователем**, не импортировано. Импортировать —
только эти 9 строк вручную/фильтрованным скриптом, **никогда** полный
`scripts/import_master_catalog.py` на проде (он повторно добавит ~46 ранее удалённых
упражнений, см. заметку prod-деплоя 2026-09-21).

## Итого

- 9 новых упражнений: 6 закрывают B2 (pull/skill, hip_hinge/skill), 3 закрывают A (power d1
  squat/hip_hinge/pull) — вместе это ~96 из ~200 fallback'ов исходной симуляции.
- Ничего не меняет в самом difficulty-гейте (пользователь явно просил не ослаблять cap,
  безопасность важнее) — закрывает пробел контентом, а не правилами.
- После импорта — повторный прогон 52-недельной симуляции на копии прод-БД, чтобы
  подтвердить снижение числа fallback'ов по причинам A и B2 (измерительная обвязка вне
  репозитория, см. memory `project_archetype_fallbacks` — как её пересоздать при повторном
  замере).
