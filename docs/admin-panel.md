# Админ-панель — инструкция

Внутренний инструмент для наполнения контента (упражнения, навыки,
справочник) и управления пользователями. Не рассчитан на публичную
аудиторию — доступен только тем, у кого выставлен флаг администратора.

## Как зайти

1. Открыть `/admin` в приложении (или ссылку "← В приложение" в шапке
   админки ведёт обратно, работает и в обратную сторону — набрать
   `/admin` вручную в адресной строке залогиненным пользователем).
2. Если видите редирект/отказ — у аккаунта не выставлен `is_admin`.
   Назначить админа можно только через сервер (в интерфейсе такого
   действия нет специально — первого админа неоткуда взять иначе):

   ```bash
   docker compose -f docker-compose.prod.yml exec backend python scripts/set_admin.py <username>
   ```

   Обратите внимание — это **username**, не email (у новых аккаунтов
   username генерируется автоматически из email при регистрации и
   нигде в интерфейсе не показывается). Если не знаете username,
   посмотреть его можно через страницу "Пользователи" в самой
   админке (см. ниже) — она ищет по email, а не по username, так что
   сначала нужно, чтобы админом стал хотя бы один человек. На новом
   сервере с нуля — проще всего посмотреть в базе:

   ```bash
   docker compose -f docker-compose.prod.yml exec postgres psql -U hockey -d hockey_level_up \
     -c "SELECT username, email FROM users WHERE email='<email>';"
   ```

3. В шапке — 4 раздела: **Упражнения**, **Навыки**, **Справочник**,
   **Пользователи**. На телефоне пункты меню и таблицы переключаются
   на список карточек, но весь функционал одинаковый что на
   компьютере, что на телефоне.

## Упражнения (`/admin/exercises`)

Каталог упражнений, из которого система собирает тренировки. Каждое
поле не просто описание — часть реально что-то определяет в подборе:

- **Категория** (Лёд/Сухая) и **Фаза** (Разминка/Основная
  часть/Заминка) — в какие тренировки и в какое место сессии
  упражнение вообще может попасть.
- **Инвентарь** — сужает подбор для игроков без доступа к залу/дому
  (сухие тренировки только; на льду инвентарь никогда не
  ограничивает выбор).
- **Сложность (1-5)** — вместе с уровнем игрока определяет, какие
  упражнения ему вообще доступны, а фаза текущего тренировочного
  блока (накопление/интенсификация/разгрузка) смещает выбор внутри
  доступного диапазона сложнее/легче.
- **Характеристика** (Целевые статы, отдельная секция после
  сохранения упражнения) — какие характеристики игрока (сила,
  ловкость, интеллект и т.д.) упражнение растит. Первая выбранная —
  основная, именно по ней система старается разнообразить подборку
  за тренировку; остальные — дополнительные, их порядок не важен.
- **Двигательные паттерны** (отдельная секция) — по ним разминка и
  заминка подбираются так, чтобы соответствовать основному блоку
  тренировки (например, если основная часть — упражнения на ноги,
  система постарается взять разминку с тем же паттерном). Если не
  проставить — упражнение просто не будет попадать в такой
  "подогнанный" подбор, ничего не сломается, но подбор станет менее
  осмысленным.
- **Stimulus type** (сила/мощность/выносливость/навык/мобильность) —
  определяет рекомендованный отдых между подходами, который видит
  игрок во время тренировки (силовая работа — 2-3 минуты, мобильность
  — 15-30 секунд). Если не задано — время отдыха просто не
  показывается для этого упражнения.
- **Exercise type** (Подходы/повторения или Время) — определяет, как
  считается длительность блока для честной оценки времени сухой
  тренировки (`~NN мин` на странице тренировки/недели). Для типа
  "Время" читается длительность в секундах; для "Подходы/повторения"
  время оценивается по числу подходов/повторений и отдыху между ними.
- **Группа мышц** — справочно, не участвует в подборе тренировок
  напрямую.
- **Подходы/Повторения/Длительность** — целевой объём, который видит
  игрок и от которого считается длительность (см. Exercise type
  выше). Можно оставить пустыми, но тогда оценка длительности
  тренировки уйдёт в грубый запасной вариант.
- **Учитывает рабочий вес** + **Коэффициент веса тела** — включает в
  логгере подходов поле для веса; коэффициент — это множитель от
  собственного веса игрока для упражнений вроде подтягиваний
  (используется, только если чекбокс включён).
- **Подходит для дня игры** — включает упражнение в пул лёгкой
  активации перед матчем. В день игры в тренировке вообще нет ни
  основного блока, ни заминки — только одна разминка-активация,
  собранная из упражнений с этим флагом (и с льда, и с сухих сразу,
  без разделения по категории).
- **Связанные навыки** (отдельная секция, "transfer note") — привязка
  упражнения к развитию конкретного навыка с пояснением, как именно
  оно помогает (показывается игроку в описании навыка).

Фильтры над списком (Категория/Фаза/Характеристика — идут запросом на
сервер; Stimulus type/Exercise type — фильтруются на месте в браузере,
так как каталог небольшой и уже весь загружен) — только для навигации
по списку, на подбор тренировок не влияют.

**Удаление упражнения необратимо** — подтверждающий диалог есть, отмены
после подтверждения нет.

## Навыки (`/admin/skills`, детали — `/admin/skills/:id`)

- **Требуемый уровень** — с какого уровня игрока навык вообще
  появляется в выборе (шаг "Навыки" в онбординге и в настройках).
  **Важно**: сейчас почти у всех навыков это значение = 1 (дефолт), то
  есть требование фактически ничего не блокирует — любой навык
  доступен с самого начала. Если это должно работать как прогрессия
  ("сложные навыки открываются позже") — значения нужно проставить
  вручную по каждому навыку через эту страницу.
- **Веса характеристик** — на сколько развитие навыка коррелирует с
  ростом каждой характеристики (сила/ловкость/...). Сумма весов
  **должна** быть ≤ 1.0 — интерфейс подсвечивает красным, если сумма
  превышена, но технически сохранить всё равно можно, это не жёсткая
  проверка на сервере.
- **Пороги** — вехи прогресса по навыку (0-100, с названием и
  описанием) — показываются игроку как ориентиры того, что уже
  достигнуто и что дальше.

**Удаление веса/порога/самого навыка необратимо**, как и с
упражнениями.

## Справочник (`/admin/reference-articles`)

Статьи (правила, экипировка и т.д.), которые видят игроки в разделе
"Справочник". Название + свободная категория (можно выбрать
существующую или вписать новую) + тело в Markdown (поддерживаются
заголовки, жирный/курсив, списки, картинки через `![](url)`).

Картинку в тело статьи можно вставить кнопкой "Вставить картинку" —
но только после того, как статья один раз сохранена (кнопка
неактивна для ещё не созданной статьи, потому что картинке нужен
`id` статьи). Отдельно от текста статьи можно загрузить обложку —
секция "Изображение" внизу формы.

## Пользователи (`/admin/users`)

Поиск по email/имени/фамилии, постранично по 20. Два переключателя на
каждого:

- **Админ** — доступ к этой самой панели. **Нельзя снять права с
  последнего администратора в системе** — сервер это блокирует явной
  ошибкой, просто назначьте кого-то ещё админом сначала.
- **Премиум** — доступ к премиум-функциям (например, ИИ-чат с
  тренером, когда он включён).

Оба переключателя сохраняются сразу по клику, без отдельной кнопки
"Сохранить".

## На что обращать внимание в целом

- Все удаления (упражнение, навык, вес характеристики, порог, статья)
  — необратимы, без корзины/отмены.
- `required_level` навыков сейчас не расставлен осмысленно (см. выше)
  — если начнёте его проставлять, учтите, что это сразу ограничит,
  какие навыки видят игроки с низким уровнем.
- Пустые `stimulus_type`/`exercise_type`/`movement_pattern` не ломают
  подбор тренировок, но снижают его качество (нет отдыха между
  подходами, грубая оценка длительности, разминка/заминка не
  подобраны под основной блок) — для нового упражнения стоит
  заполнять все поля, а не только обязательные.
